# Página de Cliente / Avatar — Instrucciones por Sección

Instrucciones detalladas, sección por sección, para construir las páginas de cliente basadas en `design/client-pages.md`.

Enfoque: estructura, layout y contenido. Sin estilos (colores, fuentes) ni código.

## Sección 1 — HERO (página de referencia: A2 Dr. Resultados)

### Estructura / Layout

```
┌───────────────────────────────────────────────────────────────┐
│ [eyebrow — etiqueta corta, 1 línea]                            │
│                                                               │
│ H1 — promesa específica del avatar (1 línea, máx. ~70 chars)   │
│                                                               │
│ H2 — sub: solución + beneficio del avatar (1–2 líneas)         │
│                                                               │
│   [ CTA principal ]   [ CTA secundario ]                      │
│                                                               │
│ ────────────── badges de confianza (1 fila) ──────────────     │
└───────────────────────────────────────────────────────────────┘
```

**Elementos y roles:**
- **Eyebrow:** una etiqueta de contexto que identifica al avatar (a quién está dirigida la página).
- **H1:** la promesa única; solo puede existir uno por página. Cierra con punto.
- **H2:** expande el H1 con el beneficio concreto para este avatar.
- **CTA principal:** ancla al formulario (sección 5). Texto en imperativo, dirigido al avatar.
- **CTA secundario:** ancla a la galería (sección 3).
- **Badges:** 5 atributos de confianza en una fila, separados por punto mediano.

## Sección 2 — DOLOR → SOLUCIÓN (página de referencia: A2 Dr. Resultados)

### Estructura / Layout

```
DOLOR                          → SOLUCIÓN vetoxzyn®
─────────────────────────────────────────────────────────────
[dolor 1 del avatar]           → [respuesta vetoxzyn®]

[dolor 2 del avatar]           → [respuesta vetoxzyn®]

[dolor 3 del avatar]           → [respuesta vetoxzyn®]
─────────────────────────────────────────────────────────────
Bullets de valor (3, siempre los mismos):
 1. Tecnología Biomimética — imita la respuesta natural celular
 2. Seguridad Superior — alta tolerancia en tejido vivo
 3. Rentabilidad Operativa — protege el equipo / evita corrosión
```

**Elementos y roles:**
- **3 pares Dolor → Solución:** cada fila presenta un dolor concreto del avatar (izquierda) y la respuesta de vetoxzyn® (derecha). El dolor se escribe como frase que el avatar reconocería; la solución siempre usa el wording seguro del manual (filtro P.A.I.N.).
- **3 bullets de valor:** siempre los mismos tres atributos; el texto de cada uno puede ajustarse levemente al contexto del avatar sin cambiar el concepto.

| Dolor | Solución vetoxzyn® |
|---|---|
| El cloro corroe tu instrumental y encarece su reposición. | Tecnología oxidativa de vetoxzyn® con **cero corrosión**: protege tu inversión y optimiza tus márgenes. |
| Necesitas una limpieza tópica segura sin dañar el tejido. | Fórmula biomimética de alta pureza y muy baja irritabilidad que **mantiene condiciones higiénicas óptimas** en la piel. |
| Los protocolos dejan residuos y riesgo regulatorio. | Auxiliar de higiene y bioseguridad: **biodegradable, sin residuos persistentes**, sin inducir resistencia microbiana. |

**Bullets de valor (fijos):**
1. **Tecnología Biomimética** — imita la respuesta natural celular para una limpieza profunda.
2. **Seguridad Superior** — alta tolerancia y seguridad en tejido vivo; no citotóxico en su uso adecuado.
3. **Rentabilidad Operativa** — protege el equipo de trabajo evitando la corrosión acelerada de los metales.

- Los 3 bullets de valor son siempre los mismos conceptos; solo se adapta su redacción al avatar.
