# Design Update — Asymmetric Layered & Floating Card

> **Design Update Prompt:**
> "Refactor the current page layout (create a new version) and image section components to adopt an **Asymmetric Layered & Floating Card** aesthetic while strictly preserving all existing brand styles (colors, typography, font weights, and button styling).
> **Specific Modifications:**
> 1. **Section Layout & Structure:**
> * Re-architect feature, hero, and content sections into asymmetrical two-column layouts.
> * Convert background content blocks into clean, high-contrast, rounded cards (`border-radius: 16px–24px`) with soft, diffuse drop shadows to establish visual depth.
>
>
> 2. **Media & Image Treatment:**
> * Elevate key section images onto floating visual cards positioned to **overlap** the edge of the adjacent text container (`z-index` layering).
> * Apply a subtle organic rotation to media cards (approx. `-2deg` to `-4deg` tilt).
> * Format images with rounded corners, heavy drop shadows, and contextual HUD/AR-style data overlays or dynamic badge elements (e.g., status pill tags in top/bottom corners).
>
>
> 3. **Typography & List Features:**
> * Maintain current brand typography and colors for headings and body copy, but structure descriptive feature lists vertically using subtle circular icon badges on the left of each item.
> * Ensure generous internal padding inside text containers to maintain clean whitespace."
